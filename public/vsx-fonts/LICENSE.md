# Video Forge caption fonts — licenses

Self-hosted webfont files (woff2, latin + latin-ext subsets) served to the
Video Forge editor preview and bundled into the render-worker so caption
rendering is deterministic and needs no runtime font CDN. Files were obtained
from Google Fonts (via google-webfonts-helper) on 2026-08-06.
